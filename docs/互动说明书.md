## 〇、先说清楚：她说话有**两个来源**（这是之前"台词不一致"的原因）

桌宠的气泡是**同一个显示区域**，由两个来源轮流写：

| 来源 | 什么时候出现 | 例子 |
|---|---|---|
| **① 桌宠本地台词**（我为互动写的） | 你触发互动时**立即显示**，互动台词保持约 **1.5–4 秒**，提醒类（内存/磁盘/下载完成等）**6–9 秒** | `三连击！你今天心情不错嘛`、`@_@ 转晕了…让我缓一下` |
| **② DSH 桌面宠插件自己的台词**（`@linxin666/dsh-pet`） | 本地台词时间到之后接管；**平时你看到的基本都是它**，按会话阶段/工具变化 | `正在使用 pwsh`、`召唤 pwsh 出击`、`借助 pwsh 的力量`、`翻翻脑子里的藏书`、`让我康康这个门道` |

**所以**：如果你只看过 `召唤 pwsh 出击` 这类句子，那是来源②，不在本文档第一节的"我的台词"里——两处我都列全了。

**另一个真 bug（已修）**：本地台词有 4 秒冷却，同一彩蛋在 4 秒内触发两次时，冷却会让它返回空、于是显示**兜底短句**（例如只显示"三连击！"而不是完整句）。现在改成了 0.6 秒冷却，并且兜底文本与正式台词**完全一致**。

**怎么核对**：日志里每次反应都会记下真正显示的句子，例如
`reaction Combo1 (line combo1): 三连击！你今天心情不错嘛`，可以和本文档逐字对照。

## 一、基础互动（不需要条件）

| 操作 | 效果 | 备注 |
|---|---|---|
| **左键单击她** | 摸摸头：台词 + 提升 DSH 亲密度 | 单击 = 按下后**不移动**再松开 |
| **双击她** | "耶！" + 播放跳跃动画 | 只有双击这一下会庆祝，连点更快不会重复播 |
| **按住她拖动** | 把她拖到任意位置；松手后自动吸附到最近的左/右边缘 | 拖动中她会说"放我下来"之类 |
| **快速甩动**（见下方彩蛋） | 转晕 | 拖动时左右来回切换方向 |
| **右键点她** | 打开菜单（分组式，30+ 项，随显示器数量与 DSH 状态变化） | 只有按 Esc、选中一项、或在菜单外面点一下才会关闭；鼠标移开不会关 |
| **悬停在她身上** | 鼠标不穿透（可以点到她）；离开她的像素范围后点击会穿透到下面的窗口 | 命中判定用精灵图的透明通道，不是矩形 |

## 二、隐藏彩蛋（8 种）与**精确触发方式**

> 前 3 项在 P5 之前**因为代码 bug 根本不可能触发**，现已修复。下面是修复后的真实阈值。

### 1. 三连击 / 六连击 / 转晕（连点）

- **三连击**：**1.8 秒内点她 3 下** → 随机其一：
  - `三连击！你今天心情不错嘛`
  - `点这么多下，是有什么好事？`
- **六连击**：**1.8 秒内点她 6 下** → 随机其一 + 跳跃动画：
  - `好啦好啦，我知道你很喜欢我！`
  - `再点下去我要冒星星了……`
- **转晕**：**1.8 秒内点她 12 下** → 随机其一 + 失败动画：
  - `@_@ 转晕了…让我缓一下`
  - `别点啦别点啦，头晕！`
- 操作要点：**一直快速连点**即可；双击的那一下也会计入连点，不会打断节奏。

### 2. 长按（按住不动）

- **按住她不放、并且完全不移动光标，持续 1.4 秒** → 随机其一：
  - `你…就这样一直摸着我不说话？`
  - `被摸久了也会不好意思的……`
- 操作要点：按住后**手不要抖**；只要光标移动超过 3px 就算拖动，长按不会触发。

### 3. 转晕（甩动）

- **按住她拖动，左右来回换方向 4 次，每段位移超过 6px、4 次都在 2.5 秒内** → 同"转晕"那两句
- 操作要点：像"摇一摇"那样**左右左右**快速甩动；小幅抖动（小于 6px）不算。

### 4. 吃撑

- **60 秒内喂她 4 次小鱼干**（右键菜单 →「喂小鱼干」）→ 随机其一，并**拒绝**第 4 次投喂：
  - `嗝——吃不下了，真的吃不下了`
  - `小鱼干先存着，等下再吃好不好`
- 操作要点：每次要重新右键打开菜单；4 次都要在 1 分钟内完成。

### 5. 角落安家

- **把她拖到屏幕任意一个角落**（距边缘 40px 以内），**然后放着不动 2.5 秒** → 随机其一：
  - `这个角落视野真好，我就在这儿扎根了`
  - `贴边站好，谁也别想让我挪窝`
- 每次停留只触发一次；**把她拖走再拖回来**会重新触发。

### 6. 整点报时

- **整点那一分钟（HH:00）** 自动触发 → 随机其一（同小时内不重复）：
  - `整点报时：又过了一小时，起来动动？`
  - `当当——又是一个整点，进度如何？`

### 7. 深夜

- **凌晨 2:00–4:59** 之间，每晚会自动触发一次 → 随机其一：
  - `两点多了，你也该睡了……我陪你再写一会儿`
  - `夜深了，记得喝水，别硬撑`

### 8. 久别重逢

- **20 分钟完全不碰她**之后，再单击她 → 随机其一：
  - `你回来啦！我等了好久`
  - `好久没见，还以为你把我忘了`
- 注意：全新启动的实例没有"沉默期"记录，所以刚开机就点她不会触发这一条。

## 四、右键菜单里能做什么（约 30+ 项，随显示器数量与 DSH 状态变化）

| 菜单项 | 说明 |
|---|---|
| 摸摸头 / 喂小鱼干 | 互动，会同步给 DSH 涨亲密度（喂太快会被她拒绝，见彩蛋） |
| 搬到 主显示器 / 副显示器 N | 勾选当前所在屏 |
| 贴右下角 | 回主屏右下角 |
| 暂停动画 / 继续动画 | 暂停时她静止但仍可见 |
| **开始/停止番茄钟** | 显示剩余时间；时长按"自动"或你选的分钟数 |
| **番茄钟时长：自动 / 15 / 25 / 45 / 60** | 点一次往后循环 |
| **开启/关闭低内存模式** | 勾选状态；可用内存 <12% 时会自动开启 |
| **开机自动启动** | 用户级 `HKCU\Run`，**不会弹 UAC**；勾选状态如实显示 |
| **切到 DSH 窗口 / 把 DSH 窗口叫回来 / 启动 DSH** | **标签随 DSH 实时状态变化**（可见 / 在托盘 / 没运行） |
| **把 DSH 收进托盘（关闭窗口）** | **仅当 DSH 可见时出现**；效果等于点 DSH 窗口的 ×（她自己收进托盘） |
| 监控面板 / C 盘清理 | 打开对应悬浮卡片（四边可缩放）；监控面板里有**内存大户**清单 |
| **长任务完成提醒：开/关** | 默认开。DSH 连续跑满 3 分钟后结束时会提醒你（完成或失败），并弹托盘气泡 |
| 隐藏（热键唤回） | 把她藏起来；托盘左键 / 热键（本机注册到的是 `Ctrl+Shift+W`，以托盘提示为准）/ 再运行一次脚本都能唤回 |
| **退出小鲸娘** | **完整退出**（写状态、清"未干净退出"标记，所以下次不会再听到"我摔了一跤"） |

**她也实时盯着 DSH**：每 1 秒判断一次（主循环 1 秒一拍），状态变化时气泡会主动说话——
`DSH 打开了！` / `DSH 收进托盘了` / `DSH 又回来了` / `DSH 关掉了，我先在这儿等你`。
（完全关闭后的那 2–4 秒里 Electron 进程还在退出，属于正常，之后立刻播报。）

## 四·补、安装与更新（**必读**，否则她无法启动 DSH）

工作区 `...\default-workspace` 被 DSH 打上了 **Low 完整性标签**，里面的可执行文件**无论谁启动**都是受限进程 → 它无法创建正常子进程（启动 DSH 会 `0x80000003`、连 explorer 都会 `0xc0000142`）。因此：

1. **安装（或每次我重新编译后）**：在**文件资源管理器**里双击
   `whaledesk\scripts\install.cmd`
   → 复制到 `%LOCALAPPDATA%\WhaleDesk`、清掉继承标签、**装上她的专属图标**并建桌面快捷方式（会先请正在运行的她退出）
2. **日常启动**：只从**桌面快捷方式「小鲸娘」**（或开始菜单）启动——这才是正常（Medium）权限
3. **确认权限**：双击 `whaledesk\scripts\run-whaledesk-diagnose.cmd`，看 `trust=...integrity=Medium(0x2000)` 即正确
4. **退出**：右键她 →「退出小鲸娘」；或托盘右键 →「退出」；或 `WhaleDesk.exe --quit`

## 五、番茄钟（含**自动设置专注时间**）

### 时长怎么定

- **「自动」模式（新增，默认）**：点「开始番茄钟」时按当前情况自动挑：

| 情况 | 时长 | 提示语 |
|---|---|---|
| 可用内存 < 12% | **15 分钟** | 内存只剩 N%，先来短的 |
| 凌晨 22:00–5:00 | **20 分钟** | 夜深了，短一点 |
| **DSH 正在会话中** | **45 分钟** | DSH 正在会话中，来一轮长的 |
| CPU ≥ 60% | **25 分钟** | 机器有点忙，中等长度 |
| 其它 | **30 分钟** | 状态不错，标准长度 |

- **手动指定**：菜单「番茄钟时长」点一下往后循环 `自动 → 15 → 25 → 45 → 60 → 自动`，选了固定值就按你选的走。
- 开始时会用气泡告诉你**这次选了多少分钟、为什么**。

### 运行中

- 她的气泡每 5 秒刷新倒计时：`🍅 专注中 24:35`
- 专注结束 → "🍅 专注结束！" + 跳跃动画，自动进入 **5 分钟休息**（倒计时显示 `☕ 休息一下 04:59`）
- 休息结束 → 提示可以再来一轮；**完成的番茄数会被记住**
- **重启不丢**：进度存在状态文件里，重启后接着走
- 想中途停止：菜单 →「停止番茄钟（剩余 12:34）」

## 六、两个悬浮卡片

| 卡片 | 打开方式 | 能做什么 |
|---|---|---|
| **监控面板** | 右键菜单 / 托盘 | CPU / 内存 / GPU / 显存 / 磁盘 / 网络 / 占用最高的 3 个进程；进度条按阈值变色 |
| **C 盘清理** | 右键菜单 / 托盘右键「C 盘清理…」 | 一组白名单目标（按可放心清理/需留意/系统文件分组），**只读扫描**；每项都有「作用 / 删除影响 / 结论」；点行尾「清理」→ 出现「确认 / 取消」→ 再点确认才删，默认进回收站（系统关掉回收站时会明示"永久删除、无法还原"）；管理员项有「提权清理」（弹 UAC） |

- **两个卡片都能拖动四个边框调整大小**：光标靠近边框（**内外约 8–16px 的范围内**）就会变成双向箭头，向外拖变大、向内拖变小；宽度 300–620、高度 110–720，尺寸会记住。
- 卡片会自动避让：她在屏幕上方时卡片出现在**下方**，在左半边时卡片**左对齐**，并且她本人的位置不会变。

## 七、低内存模式 / 开机自启 / 自恢复

| 功能 | 说明 |
|---|---|
| **低内存模式** | 空闲时把采样从 5 秒拉到 20 秒、帧率从 30fps 降到 15fps、渲染降到低画质；**可用内存低于 12% 时自动开启**，也能在菜单手动开关 |
| **开机自启** | 写 `HKCU\...\Run`（**按用户级，不会弹 UAC**）。菜单里点一下开启，再点一下关闭；如果系统策略禁止写注册表，界面会明确告诉你失败原因 |
| **自恢复** | ①上次异常退出→启动时她会说"上次我摔了一跤，已经自己爬起来啦"；②资源管理器重启→托盘图标自动重新出现；③被全屏游戏抢走置顶→自动重新置顶；④DSH 断开→轮询从 800ms 退到 1.5 秒安静重试，恢复后提示"连上 DSH 了" |

## 八、排查：为什么我按了没反应？

| 现象 | 原因 |
|---|---|
| 我看到的句子和说明书不一样 | **先看第〇节**：气泡有两个来源。你看到的很可能是 DSH 插件自己的台词（如 `召唤 pwsh 出击`），本地互动台词只显示 1.5–4 秒就被它接管（提醒类 6–9 秒）。要对账请看日志里的 `reaction … : <句子>` |
| 「打开 / 启动 DSH」没反应 | 该操作不强行改 DSH 的窗口状态；若 DSH 在托盘或系统限制了跨进程窗口操作，请直接点 DSH 托盘图标或任务栏 |

## 九、P1 新增：长任务提醒 / 状态浮标 / 内存大户

### 长任务完成提醒
- **什么算长任务**：DSH 在连续工作（准备、等回复、思考、整理、调用工具、读写文件）**持续 3 分钟以上**，然后结束。
- **你会看到**：她会说 `长任务完成啦（用了 4 分 12 秒）` 或 `长任务失败了（跑了 4 分 12 秒）`，同时播放跳跃/失败动画，并弹一个**托盘气泡**——你人在别的程序里也能看到。
- **不会打扰你**：短于 3 分钟的任务不提醒；DSH 中途断开时只结束计时、不猜成败。
- **开关**：右键菜单 →「长任务完成提醒」，状态会被记住。

### 会话状态浮标
她脚下会出现一个小胶囊：`DSH · 工具中 · 03:12`（当前阶段 + 已经跑了多久），每秒刷新。DSH 空闲时自动消失，点它不会挡住摸她。

### 内存分级预警 + 内存大户
| 可用内存 | 她的反应 |
|---|---|
| < 15% | 气泡提醒"内存有点紧" |
| < 10% | 气泡 + **托盘告急** |
| < 5% | 气泡 + **托盘告急**，建议马上关大户 |

打开**监控面板**，底部有「内存大户（点一下 → 再点确认结束）」前三名：
1. **点一下**：只上膛，她会问 `再点一次就结束 chrome（1.2 GB）`（8 秒内有效）
2. **再点一下**：真的结束该进程
3. **她不会动的**：系统关键进程、DSH 本体、她自己、PID ≤ 4 的进程（点了会直接告诉你"我不会动它"）

## 十、OS 级任务监视（不限于 DSH）与"开太久"提醒

### 什么算"系统长任务"
某个程序（或同名的多个进程）**持续 3 分钟**在干活才算：
- **CPU ≥ 5%**（编译、渲染、训练、脚本…）
- **或 磁盘读写 ≥ 5 MB/s**（**大文件夹复制/大文件移动**，CPU 很低也能抓）

**不会误报**：听歌、挂机、开着的常驻程序（CPU 1–2%、不占磁盘）**永远不会**触发。
系统守护进程（svchost、杀毒扫描、搜索索引…）、DSH 本体、我自己也不报。

### 结束时你会看到
她会说：`chrome 跑了 6 分 12 秒，结束了`，或 `explorer 跑了 4 分 20 秒，看起来做完了 · 峰值磁盘 22.4 MB/s`，同时弹托盘气泡 + 跳跃动画。
（**资源管理器复制的活其实是 explorer.exe 干的**，所以那种情况会报 `explorer`——只提醒，不会去结束它。）

### 应用开太久（默认关）
按**在前台的时长**算，默认 **60 分钟**、同一应用 **3 小时**内只提醒一次：
`cloudmusic 已经在前台 60 分钟了，要不要喝口水、动一下？`
想用就右键菜单 →「应用开太久提醒」。

### 菜单里的三个开关
| 菜单项 | 作用 |
|---|---|
| 长任务完成提醒 | **DSH 会话**的长任务（阶段判定） |
| 系统任务提醒 | **任何程序**的长任务（CPU + 磁盘 I/O） |
| 应用开太久提醒 | 前台时长温和提醒（默认关）|

### 监控面板的大户清单（已改进）
- 现在按**应用家族**显示：`Code ×12 · 4.7 GB`（点一次上膛、再点一次结束**整族**，含子进程）
- **受保护进程不再占列表位置**，改在下方灰色汇总：`另有 N 个受保护进程（系统/DSH/我自己，不会动它们）`
- 正在忙的（CPU ≥3%）会拒绝："它正在忙，等它闲下来再结束吧"；Codex/ChatGPT 这类跑任务时更严格（CPU ≥0.8% 就拒绝）

### 一个诚实的限制
对于**不是她启动的**程序，她拿不到**退出码**，所以只能报"结束了"，不能判"成功/失败"。
如果你要自己的脚本也能判成败，告诉我，我给你 `whaledesk-run.cmd -- 你的命令` 包装器（她启动它 → 就能拿到退出码并说"成功/失败（退出码 N）"）。
### 修正：大文件夹复制的提醒规则（2026-10-17 修订）

判定**与是否跨盘无关**（同盘复制同样会提醒），只看两件事，满足任一即可：

| 情况 | 触发条件 |
|---|---|
| 慢慢搬（机械盘、网络盘） | 磁盘活动**持续 ≥ 3 分钟** |
| **快速搬（NVMe、大文件）** | **累计读写 ≥ 1 GB 且持续 ≥ 5 秒** |

结束后她会说：`explorer 跑了 20 秒，看起来做完了 · 读写约 3.2 GB（峰值 160 MB/s）`
（**100 MB 左右的小读写不会打扰你**，所以日常保存文件不会弹。）

阈值（1 GB / 3 分钟 / 5 MB/s）都可以调，觉得吵或觉得漏，告诉我改。

### v0.10.3：修崩溃 + 新增「复制到…」

**崩溃修复**
之前点快捷启动面板里的「+ 文件夹」/「+ 程序」会弹 `Exception Processing Message 0xc0000005`，点确定后小鲸娘退出。
原因：系统文件对话框弹出时让面板失焦，面板"失焦即关闭"把自己关了，对话框拿到已销毁的窗口就崩了。

所以有两种做法：
1. **粘到别的文件夹**：直接 Ctrl+V 就行
2. **一定要放进原目录 / 想自动改名**：拖文件给她 → 右键菜单 →「**复制拖入的文件到…**」→ 选目标文件夹
   → 她会自己复制，重名时自动变成 `文件名 (2).txt`，**不会弹任何 Windows 对话框**

**快捷启动的旧配置**
旧版配置文件里的 PowerShell 没有起始目录，现在会自动补成你的用户目录 `%USERPROFILE%`；想改就在「编辑配置」里改 `WorkingDirectory`。

### v0.19.0：跟随"动一下就停"已修（真根因）

- 在动：`FOLLOW moving dx=-12 dy=12 speed=320 pxs=12 rect=...`
- 被挡：`FOLLOW blocked reason=card-open|user-active|paused|dragging|arrived|close-enough|edge ...`

实测（快档）：连续 40 拍共位移 **352×90 像素**，`verdict=PASS`。

- 顺手把右下角**边距**算准了（以前会因为高度取到旧值而偏高一点）。

### 为什么会闪（给好奇的人）

旧代码是"先显示、再挪到右下角"。而在 Windows 上，这种半透明窗口第一次显示时，显示调用要 300 多毫秒才返回，返回之前窗口**已经在屏幕上画出来了**——于是先画在系统默认位置（左上角）。实测这段错位画面可见约 **370 毫秒**，肉眼非常明显。现在改成"先定位、再显示，定位完成前保持透明"。

### 验证

- `--selftest` 全过；构建 0 警告 0 错误
- 用 5 毫秒间隔轮询窗口矩形对比：旧版首帧在 (154,154)、370 毫秒后跳到 (1196,552)；新版**首帧即最终位置**，无任何位移
- 点面板外面 → 实测 120 毫秒内关闭

## 二十七、0.25.0 新增的六件事

### 1. 任务板完成了会告诉你
右键菜单 →「DSH 与监控」里会多一行：**「任务板：运行中 2 · 待办 5 · 今日完成 3」**，点它直接唤起 DSH。
任务板上的卡片从「运行中」变成「完成 / 失败」时，她会说一句 **「任务完成：《标题》」**。
> 只在她开着的时候播报；桌宠没开时完成的任务不会补播（避免一开就刷屏）。

### 2. 电池和磁盘有了「趋势」
- 电量低于 20% 且没插电时提醒一次；插上电源、或回到 25% 以上，提醒会重新武装（不会一直烦你）
- 每天记一次 C 盘剩余空间（保留 14 天），算出「每天少多少 MB、大概几天写满」
- 想看就说：菜单 →「提醒与开关」→「**电池与磁盘状况…**」，一条气泡给出结论
> 本机没有温控传感器（ACPI thermal zone），所以没有温度显示——做不到的事不写进功能里。

### 3. 每周自动清理（只清放心项）
每 7 天第一次开机时，她会**自己清一次「放心项」**：临时文件、缩略图缓存这类删了系统会重建的东西。
- **回收站不会清空、需要管理员的项不碰、只给路径的项不动**
- 和面板里手动清理**互斥**：手动清理在跑时这一轮直接跳过，不会两份清理打架
- 清完气泡汇报「回收了 X」；不想要就菜单 →「提醒与开关」→「每周自动清理放心项：关」
- **想立刻清一次**：菜单 →「提醒与开关」→「**立即清理放心项（同自动清理）**」，或在搜索面板里输入「清理」执行同一条命令

### 4. 插件落后会提醒（但不会自己升级）
她每天查一次你 DSH profile 里装的插件版本和 npm 上的最新版，落后时提一句。
- **只提示，绝不自动升级**——正在用的 profile 不能被悄悄改
- 想立刻查：菜单 →「新手与帮助」→「检查 DSH 插件更新」

### 5. 剪贴板多了「片段」
剪贴板面板现在是上下两区：
- **常用片段**：你收藏的片段，左键放回剪贴板、右键删除
- **最近复制**：原来的历史

**怎么收藏**（这次按你的意见改了）：把鼠标移到某条历史上时，右侧才浮现「**存为片段**」——
想存哪条就点哪条的按钮，**不需要先把那条点回剪贴板**。
- 文字片段：支持 `{date}` → `2026-10-24`、`{time}` → `21:05`，粘的时候自动替换
- **图片也能收藏**：图片历史行的「存为片段」会把那张图**单独复制一份 PNG** 存进片段目录，之后清空剪贴板历史也不会影响它
- 底部「存剪贴板为片段」仍然保留：适合收藏"当前剪贴板里刚复制的东西"

### 6. 搜索面板（`Ctrl+Alt+Space`）
一个输入框搜遍：**内置命令、片段、快捷启动项、剪贴板历史、算式**。

| 你输入 | 会发生什么 |
|---|---|
| `清理` | 列出「C 盘清理…」「关闭每周自动清理」等相关命令 |
| `1+2*3` | 最上面出现「= 7」，回车把结果复制到剪贴板 |
| `yj`（拼音首字母/缩写） | 按首字母匹配（如 `vsc` → Visual Studio Code） |
| 什么都不输入 | 按你平时的使用习惯列出最常用的几项 |

- `↑` `↓` 选择，`Enter` 执行，`Esc` 关闭
- 排序规则：**完全相等 > 前缀 > 子串 > 首字母缩写 > 顺序子序列**；然后在接近的结果里按使用频次/最近使用微调——**习惯可以微调顺序，但不会把模糊匹配顶到精确匹配前面**
- 热键避开你已在用的 `Win+Alt+Space`；`Ctrl+Alt+Space` 被占用时会自动退到 `Ctrl+Shift+Space`、`Ctrl+Alt+K`（以菜单里显示为准）

## 二十八、v0.25.1：副屏上的面板不再跨屏

**现象**：把小鲸娘拖到副显示器后，点「剪贴板历史」，面板会跑到主显示器的右边缘、一半在副屏一半跨出屏幕；搜索面板、快捷启动、空间分析、新手引导、引导窗口、插件体检也一样。在副屏上只有右键菜单没问题。

**原因**：这些弹出面板用的是 WPF 的 `Left/Top`（DIP 坐标），而 DIP 的原点永远是**主显示器**的左上角。于是"副屏右下角"被算成了"主屏宽度 - 面板宽"，面板就跑回主屏边缘去了。右键菜单一直用的是 Win32 物理像素定位，所以它没出问题。

**修复**：面板统一改走 `PopupFrame` 的**物理像素**定位——按小鲸娘**所在显示器**的工作区（含该显示器的原点偏移）用 `SetWindowPos` 摆位，再按 Win32 报回的真实矩形做二次校正。搜索面板改成在同一显示器上水平居中、顶部位于 22% 高度处。

**验证**：新增 `--probe-popup-placement`，在每块显示器上依次摆出剪贴板面板、快捷启动、搜索面板，逐条断言窗口矩形完整落在该显示器工作区内：

```
PLACEMENT PROBE clipboard @副显示器 2: rect=(3420,491)-(3820,1020) inside=True
PLACEMENT PROBE launcher  @副显示器 2: rect=(3500,767)-(3820,1020) inside=True
PLACEMENT PROBE palette   @副显示器 2: rect=(2570,229)-(3190,638) inside=True
```

主显示器上同样全部 `inside=True`。另有两条纯数学断言守着"副屏原点不能被忽略"。
