# WhaleDesk 技术说明

## 平台范围

本项目**仅支持 Windows 10/11 x64**。所有 UI 与系统能力都绑定 Windows：
WPF（.NET 9 Windows Desktop）、Win32 P/Invoke（user32/gdi32/dwmapi/iphlpapi）、注册表自启动、
WinForms 托盘、回收站、PDH 性能计数器、前台窗口句柄。
macOS/Linux 无法运行；跨平台需要把 UI 换为 Avalonia/MAUI 并重写各平台服务层，
且 macOS 还需签名与 notarization，**无真机验证前不宣称支持**。

## 形态
- 独立 .NET 9 WPF 进程（非 DSH 插件），单实例，低内存模式（<12% 可用内存时降帧/降采样）
- 打包为框架依赖版（约 6 MB）或自包含绿色版（约 150 MB，含 .NET 运行时）

## 模块
| 目录 | 职责 |
|---|---|
| `PetWindow.cs` + `PetWindow.Probes.cs` + `PetWindow.Updates.cs` | 主窗口编排、探针、更新检查（partial 拆分） |
| `MenuWindow.cs` / `SubMenuWindow` | 独立窗口菜单（物理像素定位，二级飞出） |
| `MonitorPanel*` / `CleanupPanel` / `AnalysisWindow` | 监控卡片、清理卡片、空间分析窗口 |
| `Monitoring\*` | CPU/内存/磁盘/GPU/进程采样、文件夹监听、桩服务器 |
| `Cleanup\*` | 目标目录分级、目录大小、深挖、清理（4 道守卫 + 回收站）、保留/忽略清单 |
| `Interaction\*` | 剪贴板历史（文本+图片）、跟随光标策略、专注策略、拖放、快捷启动、久坐 |
| `Recovery\*` | DSH 定位/可见性探测、端口发现、自启动、单实例、崩溃恢复标记 |
| `SelfTest.cs` | 126 项自检（纯逻辑 + 实时采样） |

## DSH 接口
- 轮询 `GET /api/pet/state`（1.5s 超时、800ms 间隔，连续 3 次失败降到 5s 并提示离线）
- 端口发现顺序：记住值 → 19387 → 64688 → 本机回环监听端口逐个探测 `/api/pet/state`
- 插件管理/皮肤中心接口需要登录（401），仅做能力探测，不尝试绕过

## 验证模型
| 手段 | 覆盖 |
|---|---|
| `--selftest`（126 项） | 精灵图/状态机/像素命中/DPI/清理判定/剪贴板/更新版本比较/跟随与专注策略 |
| `--rehearsal`（33 项） | 清理动作 dry-run（不删除） |
| `--probe-*`（28 个） | 菜单定位、监控/清理卡片、DSH 接口、热插拔恢复、跟随位移、图片历史、更新检查 |
| 真实日志检查 | 每轮交付附日志证据；无法自动验证的 UI 交互在说明中标注 |

## 构建
```
dotnet restore src\WhaleDesk\WhaleDesk.csproj -p:NuGetAudit=false
dotnet build   src\WhaleDesk\WhaleDesk.csproj -c Release --no-restore
scripts\build-dist.cmd                 # 框架依赖 dist\app
scripts\build-dist-selfcontained.cmd   # 自包含 150MB dist-selfcontained\app
scripts\package-release.cmd            # release\WhaleDesk-<ver>.zip + notes + sha
```
构建脚本纯 ASCII + CRLF；NuGet 的 APPDATA 重定向到工作区、关闭审计，避免锁定环境下还原失败。

## 目录
- 程序：`%LOCALAPPDATA%\WhaleDesk\`
- 状态：`%LOCALAPPDATA%\WhaleDesk\state\`（位置、开关、番茄钟、剪贴板历史与图片）
- 日志：`%LOCALAPPDATA%\WhaleDesk\build\whaledesk.log`
