# WhaleDesk 安全说明

## 它访问什么
| 数据 | 用途 | 存放 |
|---|---|---|
| 窗口位置/开关/番茄钟状态 | 恢复上次布局与设置 | `%LOCALAPPDATA%\WhaleDesk\state\*.json` |
| 剪贴板**文本**（最近 60 条） | 剪贴板历史 | 同上 `clipboard-history.json` |
| 剪贴板**图片**（最近 10 张 PNG，单张 ≤8 MB） | 图片历史 | `state\clipboard-images\` |
| CPU/内存/磁盘/GPU/进程 | 监控与告警 | 不落盘（仅内存采样） |
| 本机回环 DSH 接口 | 会话状态/阶段/气泡 | 不落盘 |
| GitHub Releases API（可选） | 检查新版本 | 不落盘 |

## 它不会做什么
- **无遥测、无埋点、不上传任何数据**（唯一出站请求是用户开启时的 GitHub 版本检查，且只读）
- 不读取浏览器历史、聊天记录、键盘输入内容
- 不静默删除：清理目标只对白名单缓存生效，执行前二次确认，删除进**回收站**（可还原）
- 不改系统设置、不装驱动、不常驻服务；自启动仅写 `HKCU\...\Run`（可在菜单关闭）
- 不尝试绕过 DSH 的登录接口（plugin-manager/skin-center 401 时仅记录）

## 权限与可见性
- 以当前用户身份运行（无管理员权限要求）；安装到 `%LOCALAPPDATA%`，不需要 UAC
- 安装时用 `icacls /setintegritylevel Medium` 清除工作区继承的低完整性标签（DSH 会给工作区目录打该标签），否则无法启动
- 日志只记录诊断信息（路径、尺寸、状态），不记录剪贴板内容与文件内容

## 网络
- 默认只访问 `127.0.0.1`（DSH 本地接口）
- 更新检查：`https://api.github.com`（可在配置里关闭；失败不打扰）
- 没有任何第三方分析/广告域名

## 卸载
1. 托盘退出 → 删除 `%LOCALAPPDATA%\WhaleDesk`
2. 删除桌面快捷方式；若开过自启动，先菜单关闭，或删 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\WhaleDesk`
3. 状态与剪贴板历史都在该目录内，删除即彻底清除

## 风险与限制（诚实声明）
- **exe 未签名**：个别电脑可能提示"未知发布者"（大多数情况直接安装即可）；如遇提示，见 README 的「防未知发布者提示」。只有文件带 MOTW 时才需要解除锁定。
- 空间分析/清理依赖目录判定规则，误判可能删掉可重建缓存（有回收站兜底）
- DSH 接口为本地约定，DSH 大版本升级可能改变字段（已做容错解析；失效时退化为本地台词）
- 桌面交互（拖拽/悬停/系统对话框）无法在自动化中完全覆盖，交付时标注需人工验证
